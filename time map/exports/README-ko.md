# 대전 대중교통 시간 지도

기준점은 `대전광역시 유성구 어은동 113-11`입니다. 첨부 레퍼런스처럼 장식을 줄이고 아래 네 요소만 남긴 피그마 편집용 SVG입니다.

- 구·동 행정 경계
- 도시철도 1호선과 공사 중인 트램 2호선
- 주요 랜드마크
- 15분 간격 시간 원

## 피그마에서 편집하기

`daejeon-transit-time-map.svg`를 피그마 캔버스로 드래그한 뒤 레이어 패널에서 그룹을 펼치면 됩니다. 선을 더블클릭하면 벡터 노드를 직접 움직일 수 있고, 그룹을 선택하면 선과 면 색상을 한 번에 바꿀 수 있습니다.

## 주요 레이어

- `02-city-area`: 지도 면
- `03-time-rings`: 시간 원
- `05-dong-boundaries`: 동 경계
- `06-gu-boundaries`: 구 경계
- `08-dong-labels`: 주요 동 이름
- `09-gu-labels`: 구 이름
- `11-subway-line-1`: 도시철도 1호선
- `12-subway-stations`: 1호선 역 점
- `14-tram-line-2`: 공사 중인 트램 2호선
- `15-tram-stations`: 트램 정거장 45개
- `17-landmarks`: 랜드마크
- `18-origin`: 기준점

시간 왜곡은 평일 낮의 도보·버스·현재 운행 중인 도시철도 1호선 접근을 조합한 디자인용 추정치입니다. 트램은 공사 노선만 표시했으며 시간 계산에는 포함하지 않았습니다.

행정 경계와 철도 선형은 OpenStreetMap 데이터를 사용했으며 ODbL 1.0을 따릅니다.
