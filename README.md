# 대전 시간지도 (timemap)

거리가 아니라 **이동 시간**으로 대전을 다시 그린 프로젝트입니다.
A1 인쇄 포스터와 인터랙티브 웹 시각화, 그리고 둘을 만든 데이터 파이프라인이 함께 들어 있습니다.

> 대전, 생각보다 가깝네?

## 무엇이 들어 있나

| 경로 | 내용 |
| --- | --- |
| `대전_시간지도/` | **인터랙티브 웹 시각화.** `index.html` 을 브라우저로 열면 됩니다 |
| `A1_하단채움.html` | A1 포스터(594×841mm) 본문 채움안 — `A1.png` 위에 얹는 레이어 |
| `A1.png` · `A1.pdf` | 포스터 원본 |
| `time map/` | 원본 프로젝트(서울 지하철 시간지도) + 대전용 파이프라인 |
| `time map/site/` | 웹 시각화 소스와 데이터 생성 스크립트 |
| `time map/exports/` | 포스터·인포그래픽 시안 (SVG · PDF · PNG) |

## 웹 시각화

```bash
open 대전_시간지도/index.html      # 빌드도 서버도 필요 없음
```

출발 정거장을 고르고 네 가지 뷰를 오갑니다.

- **지리 지도** — 실제 거리
- **시간 · 현재** — 1호선 + 버스 기준으로 왜곡된 대전
- **시간 · 트램 후** — 트램 포함. 반대 시나리오가 점선으로 겹칩니다
- **단축 시간** — 트램으로 시간이 줄어드는 지역을 격자로 표시

방위는 실제 방위, 반지름은 소요시간입니다. 노선은 정거장을 잇는 Catmull-Rom 스플라인으로
그려 어떤 왜곡에서도 꺾이지 않습니다.

## 원본 프로젝트

`time map/` 은 서울 수도권 752개 역 시간지도입니다. 여기서 다익스트라(`src/graph.ts`),
방위=지리 / 반지름=시간 투영(`src/map/projection.ts`), geo↔time 모프 렌더러
(`src/map/renderer.ts`)를 가져와 대전 트램에 이식했습니다.

```bash
cd "time map"
npm install
npm run dev        # 서울 버전 (Vite)
```

## 데이터

대전 지오메트리는 `time map/exports/daejeon-transit-time-map.svg` 를 역산해 복원했습니다.
이 SVG는 이미 시간 왜곡된 좌표라 지리 좌표가 없었는데, 왜곡 함수가 방위를 보존한다는 점을
이용해 lon/lat 을 되찾았습니다. 검증 — KAIST·대전시청·대전역 실좌표 대비 오차 0.1~0.8km,
복원 면적 533km²(실제 539.7km²).

```bash
cd "time map/site"
python3 extract.py && python3 invert.py && python3 build_data.py
node check.mjs        # 출발지별 도달면적·OD 소요시간
node headless.mjs     # DOM 스텁 위 런타임 검사
```

## 시간 모델

**공표 수치** — 트램 표정속도 22.06km/h · 본선 33.9km · 정거장 45개 · 첨두 배차 7분 30초 ·
1호선 20.5km / 표정속도 33.5km/h · 총사업비 1조 5,069억 원 · 개통 2030년 하반기(2026.6 대전시 발표).

**가정** — 직선거리 우회계수 1.3 · 도보 4.55km/h ·
시내버스 접근·대기 10분 + 표정속도 16km/h + 5km 초과 시 환승 7분 · 환승 도보 2분 + 거리.

버스 계수는 공표 자료가 없어 비교용으로 둔 값입니다. `단축 시간` 뷰는 두 시나리오의
**차이**만 보므로 이 가정의 영향을 가장 적게 받습니다.
