# 대전 시간지도 — 웹 비주얼라이제이션

거리가 아니라 **이동 시간**으로 그린 대전. 출발 정거장을 고르면 현재와 트램 도입 후의
도달 범위가 어떻게 달라지는지 보여줍니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. 빌드도 서버도 필요 없습니다.
데이터를 `fetch` 대신 `data/daejeon.js` 의 전역 할당으로 싣기 때문에 `file://` 에서도 그대로 동작합니다.

## 구조

```
timemap/
├─ index.html          마크업
├─ css/style.css       포스터 A1의 색·타이포 토큰
├─ js/app.js           캔버스 렌더러
└─ data/daejeon.js     지오메트리 · 정거장 · 통행시간 행렬  (생성 파일, 직접 고치지 말 것)
```

`js/app.js` 는 위에서 아래로 이렇게 읽힙니다.

| 구간 | 하는 일 |
| --- | --- |
| `unb64` / `tt` | 통행시간 행렬을 풀고 (출발지, 도착지) 로 조회 |
| `borrowed` | 경계 정점은 가까운 격자셀 4개를 역거리로 섞어 시간을 빌린다 |
| `layout` / `fitGeo` | 좌·우 레일을 뺀 안전영역에 지도를 배치 |
| `radial` | 반지름 = 소요시간^0.68 — 가까운 곳이 뭉치지 않게 |
| `D.routes` / `routePath` | 노선은 정거장을 잇는 Catmull-Rom 스플라인 |
| `smoothRadius` | 경계선은 반지름만 평활화(방위는 실제값 유지) |
| `tweenTo` / `step` | 지리 ↔ 시간 모프 (cubic-in-out, 1.4초) |

브라우저는 소요시간을 **계산하지 않습니다**. 전부 조회입니다.

## 네 가지 뷰

- **지리 지도** — 실제 거리
- **시간 · 현재** — 버스 + 1호선 기준 시간지도
- **시간 · 트램 후** — 트램 포함. 반대 시나리오가 점선으로 겹칩니다
- **단축 시간** — 트램으로 시간이 줄어드는 지역을 격자로 표시

## 소요시간은 어디서 오나

추정 공식이 아니라 실제 시간표로 계산한 값입니다. 상위 파이프라인이 만듭니다.

```
TAGO 대중교통 노선정보 ─┐
대전시버스운송사업조합 시간표 ─┼─> GTFS ─> r5py(R5) ─> 통행시간 행렬 ─> data/daejeon.js
도시철도 1호선 · 트램 2호선 ─┘         + OSM 도로망
```

| 항목 | 값 |
| --- | --- |
| 출발 | 2026-08-12(수) 10:00, 60분 구간의 중앙값 |
| 상한 | 150분 |
| 도보 | 접근·이탈 각 최대 15분 |
| 포함 | 도보 · 대기 · 환승 · 승차시간 전부 |

첨두시간대가 아니라 평시입니다. 첨두로 잡으면 트램에 유리하게 나오므로 보수적인 쪽을 택했습니다.

행렬은 출발지 65개 × 도착지 2207개(500m 격자 2142 + 정거장 65)이고, 분 단위 uint8 로 실려 있습니다.

### 대중교통이 닿지 않는 곳

위 조건으로 못 닿는 지점은 **가장 가까운 도달 지점까지의 시간 + 거기서부터의 도보**로 채웁니다.

```
t(닿지 않는 지점) = min over 도달 지점 c ( t(c) + 걸어가는 시간(c → 지점) )
                                        도보 3.6km/h · 직선거리 × 우회계수 1.3
```

r5py 는 한계를 넘으면 값을 아예 주지 않는데, 그대로 두면 외곽 정점이 전부 최외곽 링에
못박혀 **안쪽 네트워크가 아무리 좋아져도 시간지도 외곽선이 움직이지 못합니다**. 위 방식으로
채우면 도보 구간이 두 시나리오에 똑같이 더해지므로, 도심에서 줄어든 20분이 외곽까지 그대로
전달됩니다 — 실제 통행자가 겪는 것과 같습니다.

도보 3.6km/h 는 r5py 자체 기본값이라 행렬의 도보와 이어집니다. 우회계수 1.3 은 가정이지만
두 시나리오에 동일하게 붙으므로 **단축 시간에는 영향이 없고**, 외곽의 절대 반지름에만 작용합니다.

시간지도 상한은 200분입니다(꼬리가 150분을 넘어가므로). 넘으면 테두리에 고정됩니다.

## 남은 가정

- **트램 표정속도 22.06km/h** — 2026년 8월 현재 미공표라 모델 선택입니다.
  배차 7분 30초 · 본선 33.9km · 정거장 45개는 대전시 계획값입니다.
- **1호선 판암~반석 38분** — 대전교통공사 시간표 대조 전 값입니다.

## 데이터 출처

- 경계 — OpenStreetMap 행정경계, © OpenStreetMap contributors, ODbL 1.0
- **정거장 좌표 — OpenStreetMap.** 트램 2호선 45개는 `construction:railway=tram_stop`
  노드에 공식 정거장 번호(`ref` 201~245)가 붙어 있고, 1호선 22역은 `railway=station`
  노드입니다. 지오코딩으로 추정하지 않습니다 (`scripts/stations_from_osm.py`).
- 정거장 이름 — 대전시 「정거장(45개소) 상세 위치」 공식 문서
- 1호선과 트램이 **같은 지점**인 곳은 정부청사(19m)·유성온천(0m) 둘뿐이라 이 둘만 한
  정거장으로 합쳐 65개가 됩니다. 대동(188m)·대전역중앙시장(169m)·서대전네거리(141m)는
  따로 떨어진 승강장이라 별도 정거장으로 둡니다 — 환승 도보가 실제로 발생합니다.
- 개통 시기 — 2026년 6월 대전시 발표(2030년 하반기)

검증: 순환선 40개 정거장을 순서대로 직선으로 이으면 31.79km 로, 공표 궤도 33.9km 보다
짧습니다. 궤도에 내접하는 다각형이므로 반드시 짧아야 하고, 이 조건이 좌표 오류를 잡아냅니다.
